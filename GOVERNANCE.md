# Governance

The repository maintainer has final responsibility for releases, security response,
and repository permissions. Routine decisions are made in public issues and pull
requests using technical evidence, compatibility, maintainability, and user safety.

Material architecture changes require an RFC and an ADR. Maintainers should disclose
conflicts of interest, invite affected contributors to comment, and record the decision.
Commit access is earned through sustained, constructive contributions and may be
removed for inactivity or Code of Conduct violations. Upstream TurtleBot maintainers
retain full authority over what is accepted into their official repositories.
