# Support

Use GitHub Discussions or a clearly scoped issue for reproducible project questions.
Include ROS distribution, Ubuntu release, commit, backend, configuration, commands,
logs, and the smallest reproduction. Search existing issues first.

Safety incidents and vulnerabilities follow `SECURITY.md`. General TurtleBot 4 setup
questions belong in the official TurtleBot 4 documentation/support channels. This
community RL extension has no guaranteed response time and is not a substitute for
professional robotics safety review.
